Nordic Financial News delivers structured, English-translated financial news from 70+ Nordic-language sources across Sweden, Norway, Denmark, Finland and Iceland, with synthesized stories, company and exchange reference data, and a financial calendar of earnings, dividends and AGMs, through a REST API, a remote OAuth MCP server and the nfn CLI.

**Areas:** Company · Financial News · Nordic · Market Data · Financial Calendar · MCP · News API
